# 미션 현황

미션은 개념 폴더 안의 `missions/` 에 두고, 다 푼 미션은 `missions/completed/` 로 옮긴다.

| 개념 | 미션 | 상태 |
| --- | --- | --- |
| for_example | ForMission | ✅ 완료 |
| while_example | WhileMission | ⬜ 진행 전 |
| collection_example | CollectionMission | ✅ 완료 |
| generic_example | GenericMission | ⬜ 진행 전 |
| generic_example | WildcardMission | ⬜ 진행 전 |
| exception_example | ExceptionMission | ✅ 완료 |
| exception_example | ExceptionTypesMission | ⬜ 진행 전 |
| oop | ClassRuntimeMission | ✅ 완료 |
| oop | ObjectMethodsMission | ⬜ 진행 전 |
| oop | InheritanceMission | ⬜ 진행 전 |
| oop | AbstractMission | ⬜ 진행 전 |
| oop | InterfaceMission | ⬜ 진행 전 |
| oop | PolymorphismMission | ⬜ 진행 전 |
| oop | CastingMission | 🔸 진행 중 (TODO 3~5 남음) |

미션을 다 풀면
1. 해당 파일을 같은 폴더의 `completed/` 로 옮기고
2. `package ...missions;` → `package ...missions.completed;` 로 한 줄 수정하고
3. 이 표의 상태를 ✅ 로 바꾼다.
