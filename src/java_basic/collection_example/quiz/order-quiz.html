요구사항대로 구현되지 않은 곳을 찾아라

아래 네 개의 파트가 리뷰 요청으로 올라왔습니다. 컴파일은 전부 통과합니다. 하지만 요구사항을 만족하지 못하는 곳이 있습니다. 막히면 힌트를 1단계씩 열어보세요.

공통 요구사항

  • R1프로그램은 예외 없이 끝까지 실행되어야 한다.
  • R2같은 입력이면 어느 컴퓨터에서 몇 번을 돌리든 같은 결과가 나와야 한다.
  • R3실제로 쓰이지 않는 변수나 코드가 남아 있으면 안 된다.

입력 데이터

ORDERS = {
  "apple,3",  "banana,5",
  "apple,2",  "cherry,1",
  "banana,2", "apple,4",
  "durian,5", "cherry,1"
}
