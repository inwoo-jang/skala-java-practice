# OOP 단계별 미션

아래 순서로 한 파일씩 `main()`을 실행하세요.

1. `InheritanceMission` - 상속과 오버라이딩
2. `AbstractMission` - 일반 부모 클래스를 추상 클래스로 변경
3. `InterfaceMission` - 상속 관계를 인터페이스 구현으로 변경
4. `PolymorphismMission` - 하나의 부모 타입으로 여러 자식 처리
5. `CastingMission` - 업캐스팅과 안전한 다운캐스팅

## 진행 규칙

- 한 번에 한 줄의 `TODO`만 해결합니다.
- 실행 결과가 `[SUCCESS]`면 그 줄의 `TODO`를 `COMPLETED`로 바꿉니다.
- `[KEEP GOING]`이면 메시지의 힌트만 보고 다시 수정합니다.
- 정답을 보기 전에 “변수 타입”과 “실제 객체”를 입으로 말해보세요.
